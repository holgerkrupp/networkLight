# NetworkLight

NetworkLight is a small menu bar wrapper for Apple's `networkquality` utility. It can check network capacity on demand or at a chosen interval, save the results, and export them as CSV for further analysis.

NetworkLight supports macOS 13 and later and uses the native macOS 26 interface when available.

To support development, please report comments and bugs in Issues or open a pull request.

The app is available for free in the [Mac App Store](https://apps.apple.com/de/app/networklight/id6443917973?l=en&mt=12).
